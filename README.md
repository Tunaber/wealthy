# Wealthy — трекер личных финансов  
**Версия:** 1.0  
**Дата:** 28.03.2025  

---

## 1. Введение  
### 1.1. Назначение документа  
Документация описывает архитектуру, функциональность и этапы разработки финансового трекера "Wealthy". Предназначена для разработчиков, тестировщиков и руководителей проекта.  

### 1.2. Цель проекта  
Создание веб-приложения для учета личных финансов, расчета ипотеки, конвертации валют и мониторинга экономических новостей.  

---

## 2. Функциональные требования  
### 2.1. Основные модули  
- **Учет финансовых операций**  
  - Добавление/редактирование/удаление доходов и расходов.  
  - Визуализация через графики (столбчатые, круговые).  
- **Конвертер валют**  
  - Автоматическое обновление курсов ЦБ РФ.  
- **Ипотечный калькулятор**  
  - Расчет платежей на основе данных топ-5 банков.  
- **Новостной блок**  
  - Актуальные экономические новости.  
- **Подкасты**  
  - Отобранные командой подкасты из сферы финансов.  
- **Новостной блог**  
  - Финансовые новости.  


  

### 2.2. Интерфейс  
- Адаптивный дизайн (Material UI + Tailwind CSS).  
- Навигация: Главная, Трекер, Калькулятор, Конвертер.  

---

## 3. Архитектура  
### 3.1. Технологии  
- **Фронтенд:** React 18, React Router v6.
- **Бэкенд:** JavaScript.  
- **API:** ЦБ РФ (курсы валют),  
- **Стили:** SCSS + CSS-модули.
- **База данныз:**  PostgreSQL .


### 3.2. Структура  
```bash
src/  
├── components/      # React-компоненты  
├── styles/          # Глобальные стили  
├── utils/           # Логика конвертера/калькулятора  
└── App.js           # Основной компонент  
```

---

## 4. Установка и запуск  
1. Клонируйте репозиторий:  
   ```bash
   git clone https://github.com/wealthy-tracker.git
   ```  
2. Установите зависимости:  
   ```bash
   npm install
   ```  
3. Запустите приложение:  
   ```bash
   npm start
   ```
